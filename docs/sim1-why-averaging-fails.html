If two networks compute exactly the same function, why can’t you simply average them?

Two neural networks can look different inside yet behave identically. Averaging their weights, which is the idea behind merging models, can still produce a broken network. This page lets you see why, with one neuron.

TOY MODELOne sigmoid unit with made-up weights (w=2, b=0.5), run on the paper’s identity. It illustrates the mechanism; it is not an experimental result.

Expert notes

PAPERLakhanpal (2026), preprint v2, Sections 2 and 4.2, Appendix B.

Sign-flip symmetry
For one-hidden-layer sigmoid networks, σ(−z)=1−σ(z) gives an exact symmetry of the parameters; with permutations, the group has 2hh! elements at width h.
Completeness
For irreducible networks (Sussmann), permutations and flips are the only function-preserving transformations.
Midpoint erasure
On the straight line to the flipped copy, the unit’s (w, b, s) all vanish at α=½; its contribution to the logit changes by −s(σ(z)−½), up to |s|/2.
Linear mode connectivity barrier
B(θA,θB) = supα[L(θα) − ((1−α)L(θA)+αL(θB))]. Permutation matching cannot undo a flip.
Spare-unit path
Lemma 1: (s−t)σ(z) − tσ(−z) + (c+t) = sσ(z)+c, so the function is constant along a piecewise-linear path (existence for tanh: Farrugia-Roberts). It shows a flat path exists, not that the straight-line barrier is zero.
Scope
One hidden layer, sigmoid, 2-D tasks. ReLU has no sign flip and is open.
(w, b, s, c) ↦ (−w, −b, −s, c+s)
